### 👋 ¡Hola! Soy Cintia Losada (CinloDev)

**Frontend Engineer & Product Developer | AI Tooling & System Architect**

Me especializo en diseñar y construir aplicaciones web modernas, plataformas SaaS multi-tenant en producción y herramientas para desarrolladores. Mi enfoque combina arquitectura de software limpia (Feature-Driven Architecture, TypeScript estricto, accesibilidad), rendimiento de alto nivel y la integración de **agentes de IA y tooling avanzado** para potenciar el ciclo de vida del software.

- 🔭 **Construyendo activamente**: Ecosistemas SaaS en producción y extensiones open source para agentes de codificación.
- 💡 **Filosofía de ingeniería**: Conceptos y arquitectura antes que código; código tipado estrictamente, cero deuda técnica innecesaria y UX impecable.
- 🛠️ **Especialidad**: Next.js (App Router, Server Components), React, TypeScript, Supabase, Tailwind CSS y flujos de trabajo con agentes autónomos (Pi Coding Agent, SDD, Subagents).

## 🧩 AI Coding Agents & Developer Tooling

Herramientas y extensiones open source diseñadas para potenciar entornos de desarrollo con agentes de IA autónomos:

- **[pi-sdd-profiles](https://github.com/CinloDev/pi-sdd-profiles)**: Gestor dinámico de perfiles de modelos para SDD y subagentes en Pi Coding Agent, con modal interactivo flotante y conmutación de contexto sin reiniciar la sesión.
- **[pi-cinlodev-cute](https://github.com/CinloDev/pi-cinlodev-cute)**: Extensión de interfaz y experiencia visual para terminales y coding agents, con paleta violeta/dark, HUD interactivo y diseño responsivo.
- **[pi-task-manager](https://github.com/CinloDev/pi-task-manager)**: Dashboard portable offline en HTML y extensión de Pi para seguimiento de tareas, fases SDD y telemetría de tokens por sesión.
