### /ᐠ. ｡.ᐟ\ Hey there! I'm Cintia Losada (CinloDev)

**Frontend Engineer, SaaS Product Builder & AI Coding Agent Toolmaker**

I specialize in crafting high-performance web applications, multi-tenant B2B SaaS platforms in production, and developer tooling. My engineering philosophy puts **clean architecture first**: Feature-Driven Architecture (FDA), strict TypeScript type-safety, accessible user interfaces, and modular component systems.

In parallel, I build extensions, custom MCP tooling, and harnesses for **autonomous AI coding agents** (Pi Coding Agent, Spec-Driven Development, and multi-agent workflows), bridging human intent with precision agent execution.

- 🌸 **Aesthetic & Discipline**: Combining clean visual aesthetics (Dark & Violet / Neko-tech) with rigorous software engineering.
- 🚀 **Core Focus**: Next.js 16 (App Router, Server Components & Actions), React 19, TypeScript 5, Supabase & PostgreSQL with Row Level Security (RLS).
- 🧩 **Open Source**: Developer tools, terminal workflows, and AI harness extensions.
