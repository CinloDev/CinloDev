## 🚀 Featured Projects

### 💰 AlDía
**Personal & collaborative finance SaaS.**

A production-ready SaaS platform designed to centralize everyday financial tracking, budgeting, and shared group expenses.

- **Dashboard:** Interactive financial metrics, monthly budgets, and cash flow projections.
- **Shared Expenses:** Multi-user shared groups with independent balances and automatic debt calculation.
- **Savings Goals:** Real-time visual progress tracking toward personalized financial targets.
- **Credit Cards & Budgets:** Comprehensive payment cycle and category spending management.

🌐 **[Live Demo](https://aldia.cinlodev.com)** · 📚 **[Technical Showcase](https://github.com/CinloDev/aldia-showcase)**

---

### 🦷 CinloLabs
**Multi-tenant B2B SaaS for dental laboratories.**

An end-to-end operational management platform designed to digitize dental laboratory workflows and connect labs with dentist clients.

- **Order Management:** Full lifecycle tracking of prosthetic work orders from intake to delivery.
- **Dentist Portal:** Dedicated client portal for dentists to submit orders and monitor production status in real time.
- **Public Landing Pages:** Built-in multi-tenant website generator with customizable templates and visual theming per lab.
- **Feature-Driven Architecture (FDA):** Decoupled domain architecture (`platform`, `tenant`, `products`, `core`) enforced by CI pipelines.
- **Security & Multi-Tenancy:** Software tenant isolation backed by PostgreSQL Row Level Security (RLS) and RBAC.

🌐 **[Live Demo](https://labs.cinlodev.com)** · 📚 **[Technical Showcase](https://github.com/CinloDev/cinlolabs-showcase)**

## 🏗 Architecture & Engineering Practices

Projects showcased in this portfolio are built using modern engineering practices, including:

- **Feature-Driven Architecture (FDA)** with strict domain boundaries enforced via CI pipelines (`check-boundaries`)
- **Component-driven development** and design token consistency
- **Server Components & Server Actions** for optimal performance and secure data mutations
- **Row Level Security (RLS)** applied directly at the PostgreSQL layer
- **Role-Based Access Control (RBAC)** and comprehensive audit logging
- **Multi-tenant architecture** with complete data isolation
- **Responsive-first & Mobile-first design** tailored for complex desktop and mobile workflows
